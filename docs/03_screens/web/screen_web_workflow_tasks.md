## 1. Purpose & Context

All tasks — workflow-generated, manual, and follow-ups. Kanban or list view with drag between columns. Tasks are the to-do items that require human action, generated by workflows or created manually.

### User Goals
- See all my tasks in one place across workflows and manual
- Drag tasks between status columns (Kanban)
- Filter by assignee, priority, and source
- Track overdue items

### Entry Points
- Sidebar: "📋 Tasks" (with overdue badge)
- Approval Queue (W104): "Related tasks"
- Workflow Builder: "Create task" step

### Exit Points
- Click task → side panel detail
- Source link → original workflow/content

## 7. States

| State | Condition | Visual |
|---|---|---|
| LOADING | Fetching | Column skeletons |
| LOADED | Tasks available | Kanban/list with cards |
| EMPTY | No tasks | "🎉 Không có task nào! Hãy thư giãn." |
| HAS_OVERDUE | Tasks past due | Red badge, overdue cards with ⚠️ |
| DRAGGING | Task being dragged | Ghost card + drop zone highlights |
| ERROR | API failed | Error with retry |

---

## 8. Error Handling

| Error Type | Trigger | UI Response | Recovery |
|---|---|---|---|
| Network offline | No connectivity | Banner: "📡 Ngoại tuyến" + cached tasks | Retry online |
| Create fail | API error | Toast: "Không tạo được task. [Thử lại]" | Retry |
| Drag fail | Status update error | Card snaps back + Toast: "Di chuyển thất bại" | Retry |
| Delete fail | API error | Toast: "Không xóa được. [Thử lại]" | Retry |
| Complete fail | API error | Toast: "Không hoàn thành được. [Thử lại]" | Retry |

## 12. SvelteKit Implementation Notes

- **Route**: `src/routes/(app)/tasks/+page.svelte`
- **Server load**: `+page.server.ts` → `TaskService/ListTasks(workspace_id, assignee?)` grouped by status
- **Kanban**: `@svelte-dnd-action` for drag-drop between columns
- **Status update**: `TaskService/UpdateStatus(task_id, new_status)` — optimistic UI
- **Side panel**: Slide-over panel with task detail, subtasks, and comments
- **Overdue**: Server cron marks tasks past `due_date` — surfaced with red badge
- **Source link**: Links to originating workflow, content, or approval
