## 1. Purpose & Context

The Idea Board is the content pipeline's front door — a Kanban-style board for capturing, scoring, prioritizing, and advancing content ideas through stages: **Inbox → Evaluating → Approved → In Script → Done**. Ideas can be created manually (one-click capture from anywhere), generated by AI (batch or individual), or auto-converted from detected trends and opportunities. Each idea carries an AI-computed score predicting potential engagement, enabling data-driven prioritization over gut feeling.

### User Story
> As a creator juggling dozens of content concepts, I want to capture ideas instantly, have AI score their potential, and visually track them through my pipeline — so I never lose a good idea and always know which one to work on next.

### Business Goals
- Capture every content idea immediately (reduce idea loss rate)
- Data-driven prioritization via AI scoring (higher hit rate per published video)
- Visualize pipeline health (identify bottlenecks: too many in Inbox, too few in Approved)
- Drive AI feature adoption (AI scoring, AI idea generation, trend-to-idea conversion)
- Enable team collaboration on idea curation (multi-user Kanban)

### When This Screen Is Used
- **Daily check-in**: Creator reviews Inbox for new AI-generated ideas or trend-converted ideas
- **Planning session**: Moving ideas from Evaluating → Approved for the week
- **Inspiration moment**: Quick-add from FAB → idea instantly in Inbox
- **Content audit**: Reviewing which ideas became scripts (In Script) and which are stuck
- **Team brainstorm**: Multiple editors adding and scoring ideas collaboratively

### Entry Points
- Sidebar: "💡 Ý tưởng" under Content section
- Quick Action FAB ([W007]): "💡 Tạo ý tưởng mới" → Idea Board (Inbox, with quick-add modal pre-opened)
- Trend Radar ([W060]): "💡 Tạo ý tưởng" → prefilled idea from trend data
- Opportunity Board ([W062]): "💡 Tạo ý tưởng" → prefilled from opportunity
- Morning Brief ([W003]): "💡 Ý tưởng mới hôm nay: 3" → Idea Board filtered to today
- AI Idea Generator ([W018]): After generation → new ideas appear in Inbox
- Direct URL: `/ideas` or `/ideas?stage=inbox&source=ai`

### Exit Points
- Click idea card → `/ideas/[id]` (Idea Detail W019)
- "🤖 AI Generate" → `/ideas/generate` (AI Idea Generator W018)
- "📝 Viết script" on card → `/scripts/new?idea_id=[id]` (Script Editor)
- Card overflow → "🔗 View trend" → `/intelligence/trends/[trend_id]`

## 2. Preconditions / Postconditions

### Preconditions
- User authenticated with valid session
- User has `idea:read` permission
- Workspace has content module enabled

### Postconditions
- Stage transitions → `ideas.status` updated via API (with optimistic UI)
- New ideas → `ideas` record created with `auto_score` triggered asynchronously
- Reorder → `ideas.position` updated (within-column sort order)
- Analytics events dispatched for all interactions
- View preference (Board/List) persisted to `localStorage`
- Filter state persisted to URL params (shareable filtered views)

## 5. Displayed Data / Data Binding

| UI Element | Data Source | API | Display Format | Cache |
|---|---|---|---|---|
| Idea title | `ideas.title` | `IdeaService/List(workspace_id, filters)` | Card title, 2-line truncated | 5m TTL |
| AI score | `idea_scores.score` | Joined in list | Badge: number + color (🟢/🟡/🔴) | 5m TTL |
| Stage | `ideas.status` | Same | Column placement + badge | 5m TTL |
| Platform | `ideas.target_platform` | Same | Platform icon (🎵📸📺🐦) | 5m TTL |
| Source type | `ideas.source_type` | Same | Badge: "🤖 AI" / "✋ Manual" / "📈 Trend" / "🎯 Opportunity" | 5m TTL |
| Tags | `idea_tags JOIN idea_tag_map` | Same (eager loaded) | Chip list (max 2 visible + "+n more") | 5m TTL |
| Linked trend | `ideas.from_trend_id → trends.title` | Same (join) | Link text: "📈 {trend_title}" | 5m TTL |
| Linked script | `scripts WHERE idea_id` | Same (join) | "→ Script #{number}" link | 5m TTL |
| Published result | `published_posts WHERE idea_id → engagement_snapshots` | `AnalyticsService/GetIdeaOutcome(idea_id)` | "✅ 45K views" (on Done cards) | 1h TTL |
| Creator avatar | `ideas.created_by → users.avatar_url` | Same (join) | 24×24 avatar circle | Session |
| Pipeline counts | Computed from grouped query | `IdeaService/GetPipelineCounts(workspace_id)` | "Inbox 5 · Evaluating 3..." | 5m TTL |
| AI pipeline advice | AI-generated from pipeline state | `CopilotService/AnalyzePipeline(counts)` | Text advice with action suggestion | 1h TTL |

## 7. States / State Machine

| State | Condition | Visual |
|---|---|---|
| LOADING | Page loading | 5 column skeletons with card placeholder shimmer |
| LOADED | Data available | Full Kanban board with cards placed in columns |
| EMPTY | No ideas in workspace | Illustration + "Chưa có ý tưởng nào 🌱" + dual CTAs |
| FILTERED | Active filters applied | Filter chip bar visible. Cards filtered. "Đang lọc: {description} [Xóa]" |
| FILTERED_EMPTY | Filters match nothing | "Không tìm thấy ý tưởng nào với bộ lọc này. [Xóa bộ lọc]" |
| DRAGGING | Card being dragged between columns | Card "lifts" with shadow (rotate 3°). Source column: dashed outline. Target column: drop zone highlights blue. |
| REORDERING | Card being moved within column | Insertion gap indicator where card will drop |
| SEARCHING | Search active | Search results highlighted. Non-matching cards dimmed (50% opacity). |
| SCORING | AI scoring in progress (on card) | Score badge shows mini spinner instead of number |
| LIST_VIEW | List mode active | Table layout with sortable columns |
| ERROR | API failed | "Không tải được ý tưởng. [Thử lại]" |

### Drag-and-Drop State Machine
```
IDLE → DRAG_START (mousedown + 150ms) → DRAGGING (mousemove) →
  OVER_COLUMN (different column = stage change) → DROP (mouseup) →
    OPTIMISTIC_UPDATE (card at new position) → API_CONFIRM → IDLE
    API_FAIL → REVERT (card bounces back) → IDLE
  OVER_SAME (same column = reorder) → DROP → REORDER_API → IDLE
  CANCEL (Escape) → REVERT → IDLE
```

## 11. Error Handling

| Error Type | Trigger | UI Response | Recovery |
|---|---|---|---|
| Drag fails | Network error during stage update | Card bounces back to original column with spring animation. Toast: "Không di chuyển được. [Thử lại]" | Retry drag or use overflow menu |
| Create fails | API error on idea creation | Modal stays open. Inline error: "Không tạo được ý tưởng. [Thử lại]" | Retry (form data preserved) |
| Delete fails | API error on delete | Toast: "Không xóa được. [Thử lại]" | Retry |
| AI scoring fails | Copilot service error | Score badge: "⚠ N/A" with tooltip: "AI scoring tạm thời không khả dụng" | Score appears later when service recovers (async) |
| AI scoring timeout | > 30s for scoring | Score badge: "⏳ Đang đánh giá..." | Auto-retries. Appears when ready. |
| Search fails | Meilisearch unavailable | Fallback to client-side filter on loaded data. Toast: "Tìm kiếm nâng cao tạm thời không khả dụng." | Client-side filtering |
| Bulk operation partial | Some items fail in bulk | Toast: "Đã di chuyển 8/10 ý tưởng. 2 lỗi. [Xem chi tiết]" | Detailed error per item |
| Concurrent edit | Two users drag same card | SSE pushes → card position reconciled. Toast: "{user} đã di chuyển ý tưởng này." | Board auto-syncs |

| Element | Requirement |

## 19. Technical Implementation Notes

### SvelteKit Specifics
- **Route**: `src/routes/(app)/ideas/+page.svelte`
- **Server load**: `+page.server.ts` → fetch ideas grouped by status + pipeline counts
- **URL params**: `?view=board&platform=tiktok&score_min=70&source=ai&stage=inbox&q=skincare`

### Data Fetching Strategy
```
+page.server.ts:
  const [ideas, pipelineCounts] = await Promise.all([
    ideaService.list(workspaceId, {
      platform: url.searchParams.get('platform'),
      scoreMin: url.searchParams.get('score_min'),
      source: url.searchParams.get('source'),
      stage: url.searchParams.get('stage'),
      q: url.searchParams.get('q')
    }),
    ideaService.getPipelineCounts(workspaceId)
  ])
  
  // Group by status for board view
  const columns = groupByStatus(ideas)
```

### Drag-and-Drop Library
- **Library**: `svelte-dnd-action` (SvelteKit-native, touch support)
- **Optimistic updates**: Move card immediately, revert on API failure
- **Touch support**: Long-press (300ms) to initiate drag on tablet

### AI Scoring (Async)
```
// On idea create:
1. Create idea → DB insert (score: null)
2. Card appears in Inbox with ⏳ spinner in score badge
3. Background job: CopilotService/ScoreIdea(idea_id, title, description, platform)
4. Score returned (0-100) → DB update → SSE push → card badge transitions to number+color
```

### Search Strategy
- **Primary**: Meilisearch full-text (if configured)
- **Fallback**: Client-side filter on loaded data
- **Debounce**: 300ms after last keystroke
