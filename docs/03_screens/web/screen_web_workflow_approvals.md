## 1. Purpose & Context

Centralized approval queue — scripts, assets, workflows, publish items, and AI-generated content awaiting human approval. Inline preview with approve/reject/request-changes actions. Approvals can come from manual workflow steps, content review requirements, or AI confidence gates.

### User Goals
- See all items pending my approval in one queue
- Preview content inline without leaving the page
- Approve, reject, or request changes with context
- Batch approve low-risk items quickly

### Business Goals
- Ensure quality control before content goes live
- Track approval SLA (time to decision)
- Enable multi-level approval chains
- Maintain audit trail for compliance

### Entry Points
- Sidebar: "✅ Phê duyệt" (with badge count)
- Notification: "📋 3 items awaiting your approval"
- Workflow Builder: Approval step triggers this screen

### Exit Points
- "👁 Preview" → Preview panel (inline)
- Approved item → next step in workflow

## 5. States

| State | Condition | Visual |
|---|---|---|
| LOADING | Fetching | Queue shimmer |
| LOADED | Items available | Queue with items |
| EMPTY | No pending items | "🎉 Không có items nào cần phê duyệt! Zero inbox." |
| HAS_URGENT | Items >4h old | Red badge, urgent items at top |
| PREVIEW_OPEN | Preview panel visible | Side panel with content preview |
| DECISION_MADE | Just approved/rejected | Item fades out + toast: "✅ Đã phê duyệt" |
| ERROR | API failed | Error with retry |

## 7. Error Handling

| Error Type | Trigger | UI Response | Recovery |
|---|---|---|---|
| Network offline | No connectivity | Banner: "📡 Ngoại tuyến" + cached queue | Retry online |
| Approve fail | API error | Toast: "Không phê duyệt được. [Thử lại]" | Retry |
| Reject fail | API error | Toast: "Không từ chối được. [Thử lại]" | Retry |
| Preview load fail | Asset unavailable | Preview panel: "Không tải được preview" | Retry |
| SLA breach | Item >4h without decision | Auto-escalates + Red badge: "🔴 Urgent" | Decide now |

## 11. SvelteKit Implementation Notes

- **Route**: `src/routes/(app)/approvals/+page.svelte`
- **Server load**: `+page.server.ts` → `ApprovalService/ListPending(user_id)` + `GetQueueStats`
- **Real-time**: SSE for new items + item decisions by other approvers
- **Batch**: `ApprovalService/BatchApprove(ids)` — only for items with `risk_level=low`
- **Preview**: Inline slide panel — loads content via `AssetService/GetPreview(id)`
- **SLA tracking**: Server computes `created_at - now()` per item, marks urgent >4h
- **Decision audit**: All decisions logged to `approval_audit_log` with user, timestamp, reason
